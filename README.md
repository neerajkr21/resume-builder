# Resume Builder

A simple resume maker that runs in your browser. Fill in your details and see a live A4 resume. No sign-up, no server, nothing uploaded.



## Features

- 4 templates: Classic, Modern, Bold banner, and a **College format** (logo, ruled headings, contacts on the right)
- Live A4 preview
- Drag sections to reorder them
- Export to PDF with selectable text
- Save and load your data as a file
- Optional logo upload (Default my college logo)

## How to use

1. Open `index.html` in Chrome, or use the live link: `https://neerajkr21.github.io/REPO-NAME/`
2. Pick a template, then replace the sample text with your own.
3. Click **Export PDF** and choose **Save as PDF**.

**College format tips:** write education as `Institution | Pursuing 2025-29`, start a line with `>` for a small italic line below it, and write skills as `Languages : C and C++`.

## Privacy

Everything you type stays in your browser. All sample data is fake.
